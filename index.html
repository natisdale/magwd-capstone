NEUROSPICY

Case Study Introduction

I designed Neurospicy as the capstone project created for my MA in Graphic and Web Design at Minneapolis College of Art and Design (MCAD)

Neurodiversity is pathologized in society, but it's important to recognize that neurodivergent individuals have unique strengths and perspectives. Self-understanding is the key to thriving.

Problem Statement

Neurodivergence may be overlooked in formative years, and later be discovered in adulthood.

Self-assessment can lead to self-understanding, but is complicated by the lack of a simple, centralized, reliable source of digestible information. Further, the view of differing neurotypes as pathologies creates a stigma with which makes people feel uncomfortable.

Preparation for a formal assessment can be challenging without guidance or tools to help get organized.

Solution Description

Neurospicy Info will provide resources for late or un-diagnosed neurodivergent to learn about traits associated with the six neurotypes most strongly associated with executive function.

Brand Process

  • Initial logo modeled on subway map. Wordmark based on lexend deca, included an offset information icon
  • The final logo has each the branch representing each trait connected to an executive function arc.
  • Six distinct key shapes identify each target diagnosis as an extension of the executive function arc.

Typography

A dyslexic friendly typeface, Lexend Deca, is used in all areas including site, forms, reports, and logo.

Usability Study 1

I performed a first round usability study using Typeform challenging users to complete three tasks and collect completion status and feedback. All users were able to complete the tasks. One user identified a typo. Another user reported some initial confusion logging on to complete a task, and asked for a more direct path initiate login than selecting sign in from the menu, which helped inform the final design for notes.

Component Process

Figma’s variables collections were used to tokenize color and layout information for the development phase. Component descriptions were used to note usage and implementation details. Wherever possible the same component was designed to be reused on small and large screens with layout controlled through variables to be used in implementing style sheets.

Splash Screen Process

I used a series of frames, auto advancing, to show each of the six key shapes representing the different diagnosises, building on executive function.

Usability Study 2

Circling back to the same users that participated in the first study provided validation that design changes had addressed earlier friction points. Next step is to work on expanding content under Executive Function, so that there is at least one full path for users to follow through the site, e.g. ADHD and Executive Function.

Print Design Process

I chose to use Figma rather than InDesign for the worksheets, building on the component system and variables in Figma with a print mode.

The mockups for the lenticular business card were based on exports of the six key aspects of the logo representing each diagnosis.

Deliverables

  • Downloadable note taking work sheets with lined and unlined versions.
  • Downloadable Notes Report with sections marked using key shapes.
  • File for lenticular printer
